Kas ir CarObka?

CarObka ir Java konsoles lietotne, kas paredzēta automašīnu entuziastiem, lai pārvaldītu savu iecienītāko automašīnu kolekciju, apskatītu detalizētu informāciju par transportlīdzekļiem un izmantotu praktiskus aprēķinus, kas palīdz izvēlēties izdevīgāko auto.


Galvenās funkcijas:

  • Automobiļu kataloga apskate
  • Iecienīto (favorītu) automobiļu pārvaldība
  • Lietotāja profils un reģistrācija
  • Informācijas filtrēšana un kārtošana
  • Degvielas aprēķini (cik km ar X litriem un otrādi)
  • Administratora funkcijas: automašīnu un lietotāju pārvaldība, datu rediģēšana
  • Ziņojumu un atsauksmju sūtīšana sistēmas uzturētājiem

Lietotāji tiek sadalīti trīs lomās:

  • Viesis — var apskatīt datus, bet nespēj veikt izmaiņas
  • Reģistrēts lietotājs — var pārvaldīt favorītus, rakstīt ziņojumus
  • Administrators — pilna datu kontrole un pārvaldība

Kā lejupielādēt?

Lejupielādēšanas soļi:

  1. Lejupielādējiet programmu caur mūsu vietni
  2. Atveriet lejupielādēto zip-mapi
  3. Izvelciet mapi savā datorā
  4. Atveriet terminālu un ievadiet komandas →

Sistēmas prasības:

  • Windows 10 / 11, Linux vai macOS
  • Java JDK 14 vai jaunāka (ieteicams JDK 14)
  • UTF-8 atbalstošs terminālis ar iespēju attēlot Braila simbolus (piemēram, VS Code terminālis, Windows Terminal u.c.)
